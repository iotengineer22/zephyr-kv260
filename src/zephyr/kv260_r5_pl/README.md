# KV260 FPGA PL Memory Access Test

## Overview

This project includes memory access testing for the FPGA's Programmable Logic (PL) on the Kria KV260 Vision AI Starter Kit. The tests are executed using the provided hardware overlay to evaluate and verify the memory read and write operations within the PL.

## Building and Running

To build this application, use the standard Zephyr `west` command with your target board:

`west build -p -b kv260_r5`
