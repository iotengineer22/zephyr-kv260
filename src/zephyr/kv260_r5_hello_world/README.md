# Zephyr Hello World

This repository contains the standard "Hello World" sample from the [Zephyr Project](https://zephyrproject.org/), used exactly as is without any modifications. 

## Overview

This is a simple application that prints "Hello World" to the console. It serves as a basic reference to verify that the Zephyr build environment and board flashing process are set up correctly.

## Building and Running

To build this application, use the standard Zephyr `west` command with your target board:

`west build -p -b kv260_r5`
